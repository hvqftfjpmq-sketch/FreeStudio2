# Free Studio

Бесплатный редактор для Android: фото, коллажи, видео и ИИ-инструменты.
Без рекламы, подписок, аккаунтов и водяных знаков. Всё обрабатывается на телефоне.

## Что внутри

| Раздел | Функции | Вдохновлено |
|---|---|---|
| Фоторедактор | 10 фильтров; яркость, контраст, насыщенность, тепло, оттенок, тени, света, резкость, размытие, виньетка; обрезка по пропорциям, поворот, отражение; кисть; текст; отмена (8 шагов) | Snapseed, Photoshop Express |
| ИИ | Удаление фона (нейросеть ML Kit), автоулучшение, шумоподавление, увеличение ×2, стирание объектов, замена фона цветом | PicsArt AI |
| Коллажи | 1–9 фото, ~20 шаблонов, отступы, скругления, цвет фона | GridArt, PicsArt |
| Видео | Обрезка, скорость 0.5–3×, фильтры, отключение звука, экспорт MP4 | InShot |

Сохранение: фото в `Pictures/FreeStudio`, видео в `Movies/FreeStudio`.

## Как собрать APK

1. Установите [Android Studio](https://developer.android.com/studio) (бесплатно).
2. `File → Open` и выберите папку `FreeStudio`. Дождитесь синхронизации Gradle (нужен интернет).
3. Подключите телефон с включённой отладкой по USB и нажмите ▶ Run.
4. Готовый APK: `Build → Build Bundle(s) / APK(s) → Build APK(s)`.
   Файл будет в `app/build/outputs/apk/debug/app-debug.apk`.

Требования: Android 10+ (API 29).

## Важно знать

- Проект написан без возможности сборки в среде, где он создавался, поэтому при первой синхронизации
  могут появиться мелкие ошибки (версии библиотек, API Media3). Пришлите текст ошибки — поправим.
- Удаление фона использует модель Google ML Kit: при первом запуске ей нужен интернет (Google Play Services скачают модель), дальше работает офлайн.
- «Стереть объект» — алгоритмическое закрашивание, хорошо работает на небольших объектах и простом фоне. Генеративного ИИ-закрашивания (как в Photoshop) здесь нет: для него нужна тяжёлая модель.

## Структура

```
app/src/main/java/com/freestudio/app/
  MainActivity.kt        главный экран и навигация
  Storage.kt             загрузка и сохранение в галерею
  editor/                Adjustments.kt (фильтры), ImageProcessor.kt (обработка)
  ai/AiTools.kt          ИИ-функции
  collage/Collage.kt     шаблоны и отрисовка коллажей
  ui/                    EditorScreen, CollageScreen, VideoScreen, Theme
```
